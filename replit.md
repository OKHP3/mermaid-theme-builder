# Workspace

## Overview

Flat pnpm workspace. The Mermaid Theme Builder is the root application package, and all application source lives at the workspace root. `artifacts/mermaid-theme-builder/` is a thin Replit platform package containing registration metadata, a package shell, and a preview asset. No backend, no database, no API.

## Stack

- **Monorepo tool**: pnpm workspaces (`packages: [".", "artifacts/*"]`)
- **Node.js version**: 24
- **Package manager**: pnpm
- **TypeScript version**: 7.0.2
- **Build**: Vite (output → `dist/public/`)

## Artifact

### Mermaid Theme Builder

- **Package name**: `@workspace/mermaid-theme-builder`
- **Type**: react-vite, fully static — no backend, no login, no API calls
- **Preview path**: `/mermaid-theme-builder/`
- **Port**: 18624
- **Tech**: React 19.3.1, Vite 8.3.5, Tailwind CSS 4.3.3, TypeScript 7.0.2, Mermaid.js 12.2.0
- **Version maintenance**: See `docs/technology-inventory.md` for the verified host inventory, complete package report, and daily audit plus Dependabot update process.
- **Git synchronization**: Follow `docs/github-sync.md` to publish reviewed changes and verify Replit, GitHub, and Windows parity. Use `node scripts/run-pnpm.mjs` for the pinned native package manager. See `docs/foundation-maintenance.md` for stable-release maintenance and host constraints.
- **Purpose**: Visual theme builder for Mermaid diagrams generated by humans or AI

**App icon:** Custom "Forked Flow" SVG icon — dark navy bg, cream input node, rust-orange fork connectors, orange themed output node. `src/components/AppIcon.tsx` used in header. PNG rasters generated via `node scripts/generate-icons.mjs` (pngjs, no native deps).

**Design language (OKH P³ Forge):**

- Header: always-dark `#1c3a34` (`.forge-header`) — persists across light/dark mode
- Background: warm paper token `33 18% 94%` + subtle 28px crosshatch grid
- Code panels: dark teal `.forge-code-panel` (`#0f1f1c` bg, `#d4c9b5` cream text, JetBrains Mono)
- OKHP³ identity: rust-orange `#c46a2c` for accents, version badge, footer brand name
- Footer: always-dark `#0f1a17` rail (desktop only), mirrors header tonality
- Mobile nav: always-dark `#1c3a34/97`, active tab rust-orange
- Section labels: `.forge-eyebrow` (11px, 600, uppercase, 0.07em tracking)
- Export hierarchy: primary (solid) → accent (tinted) → outline
- Fonts: Alfa Slab One (h1), DM Sans (body), JetBrains Mono (code)

Explicit saves, search beyond three themes, reviewed import, complete JSON/links, and local backup/recovery are described in `docs/complete-themes.md`. The owner approved gated merge and release on 2026-11-04. Verify the release tag and Pages run independently. Keep all Replit work in Free mode.

- **Theme-first workspace (v0.8.0):** Compose promotes the active theme and existing Save/Export/Use actions. Apply keeps source beside the preview, with focused Theme/Preview/Code views on mobile. Existing routes, storage, imports, and exports are retained; no profile migration is included.
- Paste Mermaid code → auto-detects diagram family (flowchart, sequence, class, ER, Gantt, pie, etc.)
- Built-in brand palettes: Overkill Hill, AskJamie, Glee Fully, and utility palettes
- Two-way live color editor — click color swatches to update, preview updates instantly
- Side-by-side live preview (Original vs Themed tabs)
- Generates `%%{init:...}%%` directive-based themed output
- Render-safety warnings (existing init directives, non-printable chars, long labels)
- Three exports: Styled Code, Markdown Bootstrap, Prompt Scaffold
- Extract mode: pull theme from existing themed Mermaid code
- Family-specific overrides (family-theming.ts)
- GitHub Pages compatible (pure static build)

## Post-merge

`scripts/post-merge.sh` runs the exact project pnpm pin with `install --frozen-lockfile --ignore-scripts` after every task agent merge.
